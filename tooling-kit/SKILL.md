# 成套配刀 — 加工任务主线 + 型号互锁校验

输入「加工形态 + 材料 + 加工性质」，输出成套配刀单。与替代查询（tool-selection）的区别：那边是「给一个型号找替代」，这边是「给一个加工任务配整套刀」。

## 用法

启动器在本技能目录的 `scripts/selectkit.py`（`$SKILL` = 本技能目录，即 my-skills 仓库下的 `tooling-kit`）：

```bash
py -3.13 "$SKILL/scripts/selectkit.py" 外圆 45钢 粗
py -3.13 "$SKILL/scripts/selectkit.py" 攻丝 M8
py -3.13 "$SKILL/scripts/selectkit.py" 内孔 45钢 半精 --dmin 20 --dmax 25 --depth 50
py -3.13 "$SKILL/scripts/selectkit.py" 外圆 45钢 粗 三菱 --json
```

参数：`<加工形态> <材料> [粗|半精|精] [品牌]`，可选 `--json`、`--limit N`（方案数，默认 3）、`--dmin/--dmax/--depth`（直径/孔深约束，毫米）。

加工形态：车削系（外圆/端面/内孔/仿形）、铣削、钻削、攻丝。**切槽/螺纹车削会明确报「专用刀片未区分」**——见下方铁律。

## 项目定位（换机可移植）

**环境变量 `SS_HOME`（设了就必须有效，设错直接报错）**；未设置时探测技能仓库同级目录 → 用户 home。找不到中文报错。不写盘符。selectkit 是纯源码（无 pyc 绑定），3.10+ 可跑，推荐 3.13 与其它技能一致。

## 已知坑 / 铁律（务必记住）

1. **宁可说没有，不给假配对**：切槽/螺纹车削的刀片表缺「刃宽/牙型/刀片类别」字段，shape+size 撞上就会把普通车削片判成切槽片——五项互锁全 ok 的**假配对**比没有更糟。引擎已显式声明 unsupported，遇到就如实转述「专用刀片未收录」，不要绕过去硬配。
2. **攻丝底孔查官方表，不近似**：底孔直径来自丝锥官方对照（输出里的 `drill_src` 标明来源），**不要用「公称−0.5×螺距」近似**，挤压丝锥（NRT/HRT）与切削丝锥底孔不同。
3. **五项互锁**：形状/尺寸/后角/压紧等全对上才输出成套；被挡掉的组数会在输出末尾注明（`互锁未通过被挡掉 N 组`），这是正常保护不是故障。
4. **参数口径**：样本参数表直接印了 rpm 的优先用样本值（`n_src=样本`）；铣削每齿进给要乘刃数但库没存刃数——**不硬算 vf**；车削/钻削样本给每转进给 f，vf=f×n。参数表直径 gap>25% 不套用。
5. **权威口径是 selectkit.py**：其 docstring 声明小程序云函数与本地面板都必须以它为准。本技能直调它，不做任何预计算。
6. **缺数据明确报缺**：某品牌某工序没收录（如部分品牌铣削）就直说，退出码 1 + 「选型失败/无方案」是正常语义，不是脚本坏了。

## 验收口径

- `外圆 45钢 粗` → 出刀杆+刀片+牌号+参数，互锁标记全 √。
- `攻丝 M8` → 丝锥+底孔 Ø（来源标注）+底孔钻头；库无该底孔钻头时明说。
- `切槽 ...` → 明确「专用刀片未区分」，不出假方案。
