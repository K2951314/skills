# 失效对策 — 样本原文诊断库

输入失效现象关键词，返回各品牌样本里的**原文对策句**（带出处册/页码）。数据来自 smart-selection 真源 `web/data/failure_countermeasures.csv`（2066 句，14 类统一失效分类）。

## 用法

脚本在本技能目录的 `scripts/failures.py`（`$SKILL` = 本技能目录，即 my-skills 仓库下的 `failure-diagnosis`）：

```bash
py -3.13 "$SKILL/scripts/failures.py" 崩刃 --op 铣削
py -3.13 "$SKILL/scripts/failures.py" 积屑瘤
py -3.13 "$SKILL/scripts/failures.py" 振动 --brand 三菱 --json
py -3.13 "$SKILL/scripts/failures.py" --list        # 列出失效模式与工序
```

## 项目定位（换机可移植）

**环境变量 `SS_HOME`（设了就必须有效，设错直接报错）**；未设置时探测技能仓库同级目录 → 用户 home。找不到中文报错，不写盘符。

## 实现口径（重要）

脚本**不自带查询规则**：定位项目后直接 import `web/src/brands_api.py` 的 `failures_lookup`——与网页 `/api/failures` 完全同源（同义词归一表、op 过滤、截断口径都在那一处），不会出现第三份实现漂移。brands_api 只依赖标准库，不需要起 Flask。

## 已知坑 / 铁律

1. **op 过滤必须带「综合」**：综合册是跨工序通用对策（如「积屑瘤→提高切削速度」车铣钻都适用），只按工序册过滤会丢行业通用知识。查询语义已内置（`cnt.get(op) or cnt.get("综合")`），不要自己按 op 硬筛 CSV。
2. **同义词归一**：打刀/断刀→破损/断裂，震刀/啸叫→振动/颤振，粘刀→积屑瘤，磨损快→后刀面磨损/刀具寿命……14 类模式见 `--list`。用户口语先归一再查，无命中时把可用模式列给用户换词。
3. **对策是样本原文，不替厂家发挥**：句子可能含日文/英文/符号（原文如此），转述时保留出处（册 p 页码），不要把自己的推断混进「样本对策」里；要补充分析就明确分开说。
4. **截断口径**：每品牌最多 8 句、6 个出处（与网页 API 一致）；需要完整结构用 `--json`。
5. **退出码语义**：1 = 无命中（正常，附模式提示），不是脚本故障；2/3 才是定位/加载失败。

## 验收口径

- `崩刃 --op 铣削` → 命中「崩刃/崩缺」，含综合册通用对策与铣削册对策，多品牌带页码。
- `积屑瘤` → 命中「积屑瘤」模式。
- `--list` → 14 类模式 + 工序列表。
