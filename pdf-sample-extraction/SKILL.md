# 样本数据抽取

抽取是**重复劳动 + 判断密集**的活。重复的部分交给脚本，判断的部分有固定套路——
这份技能就是把套路写死，避免每次从「先写个正则试试」重新开始。

**唯一的第一性原理**：数据的完整性只能由「样本里印了什么」定义，
**不能由「脚本跑完了、没报错」定义**。所有流程都服务于这一条。

---

## 五个阶段（每个阶段都有闸门，闸门不过不许进下一阶段）

| 阶段 | 做什么 | 产出 | 闸门 |
|---|---|---|---|
| 1 勘察 | 读书签目录 + 扫标题字号，搞清楚**这本样本里有哪些章节、每章讲什么** | 章节清单（页区间 + 标题） | 能回答「这类数据分布在哪几页」，且不是抄目录页码而是实测 |
| 2 分母 | 逐页按**版式特征**分类，生成页清单：哪些页真有这类表、哪些是噪声 | `页清单.csv` | 页数能对上样本实际；噪声页有明确判据 |
| 3 分组 | 把页按**表头签名**聚类，一种版式一组 | 版式分组表（每组页数 + 列数 + 样页） | 每组至少看过 1 页的渲染图或 span dump |
| 4 抽取 | 一组一个抽取器，先 1 页做通再扩到整组 | 主表 / 明细表 / 低置信表 | 单页对得上原文（逐字段） |
| 5 校验交付 | 四层独立校验 + 回归基线 + 验收报告 | 验收报告（含分母）+ 页清单终稿 | 每条不过的值都有去处（隔离或清单），没有静默丢弃 |

**严禁**跳阶段。历史上最大的两次翻车（泰珂洛 ap/f 空 97.7%、京瓷 1394 行是正文切片）
都不是「抽取器写得不好」，是**阶段 2 没做**：按「有没有 vc 字样」捞页，把目录页、说明页、
材质 lineup 页全捞进来了，抽出来的东西自然不是表。

## 抽取前必须回答的 8 个问题

写第一行代码之前先答完，答不出来的就是下一步要去勘察的：

1. **这类数据分布在哪几页？** 用书签 `get_toc()` + 全页大字号标题扫描实测，别信目录印的页码（PDF 物理页 ≠ 印刷页，差几十页是常态）。
2. **一页一种版式，还是好几种？** 同一章里也可能 8 种（京瓷 K 章 38 页至少 8 组）。
3. **主键是什么？** 型号？刀杆型号？还是「材料 × 牌号 × 加工径」的组合？主键错了，后面全是重复行。
4. **数值是单值、二元组、还是三元组？** `250 - 300 - 350` 的**中间值加粗 = 推荐值**，这个语义必须还原成三列。
5. **合并单元格怎么表达「共用」？** 一个 RE 覆盖 6~8 行，还是向下继承？
6. **单位写在哪？** 表头、页脚、还是副标题（`ap 为半径值`）？页级口径必须抽成列，否则下游会用错。
7. **页脚 ※ 注释会不会推翻表里的值？** 京瓷 PR1725 在易切钢要压到 Vc≤150，而表里印的是 250~350。
8. **有没有「不是文字」的信息？** ISO 材质色块、★/▲/● 标记、私用区图标字符——这些 `get_text()` 拿不到。

## 铁律（每一条都是踩过才写下的）

1. **先判「是不是表」，再抽。** 真参数表的判据是「材料域 + 数值列同时成片出现」，不是「有 vc 字样」。
   ⚠ 成组率要**按该版式应有的列算**，不是「四列齐全率」一刀切：切槽表原文就没有 ap/f，
   拿它当分母会把合法的表误判成「不是表」（这条规则最初写错过，审查时才改过来）。
   只有当「该有的列都齐」的比率仍然极低（如 <10%），才判它不是表，回阶段 2 重新定页。
2. **有框线就用 `page.find_tables()`，别手写坐标模型。** 京瓷 11 列全矩阵用 `find_tables()` 直接认出
   合并单元格，比 y 聚类省一整天；泰珂洛那套聚类是在**无框线**表格上被逼出来的。
   ⚠ 但「有框线」不等于「能无脑抽」，`find_tables()` 之后还有三步必做（见 02 篇）。
3. **列锚点来自数据 x 聚类，不来自表头。** 表头会缺、会跨列占位、会被拆成碎片（`V` + `c (m/min)`）。
4. **定行靠「列冲突」，不靠 y 容差。** 同一列出现第二个值就一定换行；y 差 7pt 的两套数值任何容差都分不开。
5. **回原文校验和值域校验必须各自独立判。** 文字能回原文 ≠ 放对了列：
   `vc='64 - 12'` 原文里确实有 `64-12`（那是每英寸牙数）。写成「能匹配就 continue」这条错永远抓不到。
6. **块级连坐。** 一个表块里只要一条值没过校验，**整块**隔离进低置信表，不进主表。
   只丢单条会把「列整体错位」伪装成「少量脏值」。
7. **主表只能从「校验 + 落盘」那一个脚本出。** 验的和导的不是同一份，是这类项目最常见的假验收。
8. **改解析器必跑回归基线。** `snap` 建基线、`check` 对比，否则改 A 页会静默丢掉 B 页。
9. **源数据矛盾不改数据，只出清单。** 样本自己印错了（Vc 与转速对不上），主表保持与样本一致，
   另出 `_矛盾清单.csv` 让下游决定。
10. **分母写清才算验收。** 「ap 非空率 24%」和「ap 非空率 100%」可能说的是同一份数据——
    分母是全部行，还是「确实有 ap 列的行」。
11. **数值解析用无锚点正则。** `re.findall(r"^\d+$")` 等价整串匹配，`'250 - '` 这种「数字+连字符同 span」
    会被整条漏掉（京瓷 p515 全是这种，直接 0 行）。
12. **旧产出故意不覆盖。** 重抽写到 `_v2`，旧文件留作对照和回滚。
13. **行数对 ≠ 数据对。** 写技能自带骨架时亲身踩到：产出 184 行、与参照**行数完全一致**，
    但所有身份列全空（`fields` 取错了字典的一侧）。只看行数/覆盖率会直接放行。
    **验收必须做值级多重集比对**，不是比行数。
14. **千分位逗号会打断区间解析。** `200 - 400 -1,000` 不先去逗号，三元组解析必失败，
    进而触发块级连坐把整页隔离。解析前统一 `replace(",", "")`。
15. **新踩的坑回填 `references/04-坑总表.md`。** 技能是这些经验的**唯一副本**，
    项目文档会过期、会被删，这里不会。每次项目里踩了新坑，回来加一行——
    不回填，这个技能就会慢慢退化成一份过时的说明书。

## 版式 → 做法（决策表）

| 版式特征 | 做法 | 关键参数 |
|---|---|---|
| 有完整框线 | `find_tables()` → 行展开 → 列语义从表头拼 | **先用 `extract_skeleton.py`**；表头行数交给它自动数 |
| 无框线、列对齐 | y 聚类成视觉行 + 数据 x 聚类成列 | `dy≈3.2`、列容差 `≈15`、表头带底 = 最深关键字行 +9.5pt |
| 多层表头（牌号 × 断屑槽） | 每层做**向右继承**再取最深行 | 不继承会少一半列（140 行 → 420 行） |
| 一页多张表 | 遍历**所有**符合版式的表，不只取 `max(col_count)` | 判据用表头关键词，不用页数 |
| 转置表（牌号在列头） | 行=材料、列=牌号，与全矩阵相反，另写一个 | 别硬套同一个抽取器 |
| 子行（一格多组参数） | 子行数 n 由 **vc 三元组个数**定，不由牌号个数定 | 其它列有 n 个值就一一对应，1 个值 = 整格共用 |
| 幻影行（只有牌号无参数） | 并回上一行（单元格 `/` 连接） | 既不能当数据行，也不能当错误 |
| 宽表（材料 × 牌号 × 直径） | 化成「材料 × 牌号 × 直径」长表 | 一页两张表要分别切块 |
| 缩印表（3pt） | 所有容差按字号缩放 | 列间距可能只有 20pt |
| 表头行数不定（1~4 行） | **不要问用户，脚本自己数** | 从 1 试到 4，取第一个「必需字段齐全且有数据行能解出 expand 值」的行数 |

## 工具（scripts/，只依赖 PyMuPDF）

```bash
# 环境：脚本一律不加 #! shebang（py launcher 会因 shebang 换解释器丢包）。
# 解释器必须装有 PyMuPDF：优先读环境变量 PDF_PY（指向该解释器的绝对路径）；
# 没设置时用 PATH 里的 python，先跑 `python -c "import fitz"` 确认再干活。
PY="${PDF_PY:-python}"

# 1 勘察单页：打印 span 坐标 / 视觉行 / 检出的表格
"$PY" scripts/pagedump.py 样本.pdf 515
"$PY" scripts/pagedump.py 样本.pdf 515 --mode lines --x0 40 --x1 552 --y0 90 --y1 790

# 2 定分母：按版式特征扫全本，出页清单
"$PY" scripts/inventory.py 样本.pdf \
    --layout "full_matrix=加工形态,推荐断屑槽,Vc" \
    --layout "drilling=加工材料,加工径,Vc" \
    --out 页清单.csv

# 3 体检既有产出（接入前必跑）：非空率 / 值域 / 中文段落 / 成组性 / 残缺值
"$PY" scripts/audit_csv.py 全量_切削参数.csv \
    --cols "加工材料,硬度,Vc,ap,f" --limits "Vc=1:2000,ap=0.01:25,f=0.001:5"

# 4 校验：数值在原文数字流里连续出现 + 身份列回原文子串
"$PY" scripts/verify_run.py 样本.pdf 主表.csv --page-col page \
    --triplet "vc=vc_min,vc_rec,vc_max" --triplet "ap=ap_min,ap_rec,ap_max" \
    --substr "grade,chip,material"

# 5 有框线的表直接用骨架抽（别从零写）。下面这条命令可复现京瓷 184 行全矩阵
"$PY" scripts/extract_skeleton.py 样本.pdf --pages 353,354,514,515 \
    --col-map "ISO=iso,加工材料=material,硬度=hardness,切削领域=domain,加工形态=form,推荐断屑槽=chip,推荐材质=grade,刀尖=re,速度=vc,切深=ap,进给=f" \
    --expand vc --carry material,iso,hardness \
    --split form,chip,grade,re,vc,ap,f --triplet vc,ap,f \
    --norm-cols material,form,chip --nospace-cols domain --tight-cols iso,hardness \
    --limits "vc=1:2000,ap=0.01:25,f=0.001:5" --require material \
    --out 主表.csv --bad _低置信.csv
```

五个脚本都是**通用**的：改 PDF 路径和参数即可，不含任何项目硬编码。
写自己的抽取器时，优先 import 它们的函数而不是复制粘贴（`pagedump.load_spans` / `visual_lines`）。

**先跑骨架再决定要不要自己写**。骨架覆盖了有框线表格的通用流程（表头自动数行、幻影行合并、
子行展开、标签归一化、块级连坐），已用京瓷 4 页全矩阵验证：**184/184 与人工验收过的产出一致**。
骨架搞不定的（无框线、两个矩阵夹一列、转置表）再按 02 篇自己写。

## 交付物规范

一次抽取任务的产出固定五个文件，缺一个就不算完成：

| 文件 | 内容 |
|---|---|
| `主表.csv` | 一行一条记录，`page` 列必填 |
| `明细.csv` | 长表（`field / col_label / value`），多子列不丢信息 |
| `_低置信.csv` | 被隔离的整块 + 问题说明列 `_err` |
| `页清单.md` | **分母**：逐页表头签名 + 抽出行数 + 拒绝原因 |
| `验收报告.md` | 覆盖页数 / 行数 / 各列非空率（**分母写清**）/ 校验结果 / 已知问题 |

CSV 一律 `utf-8-sig`（Excel 直接打开不乱码）。每张表必须有 `_备注` 列——
型号截断、范围标题、疑似误抽都要标，**不许删除**。

**验收的最后一步是值级比对**，不是看行数：

```python
from collections import Counter
# 骨架/新产出 与 参照（人工核对过的旧产出 or 上一轮基线）比多重集
key = lambda r: (r["page"], r["grade"], r["vc_min"], r["vc_rec"], r["vc_max"], ...)
print(sum((Counter(map(key, new)) & Counter(map(key, ref))).values()), "/", len(ref))
```

`只在新产出` 和 `只在参照` 都必须为 0。有历史基线可比时，这是最强的验收；
没有基线时至少做到 `verify_run.py` 的 A/B 两层 + 人工抽 3 页对渲染图。

## 什么时候必须停下来问用户

- 主键选不出来，或有两种都说得通的粒度（按刀片型号 vs 按刀杆型号）。
- 样本自身矛盾（Vc 与转速算不平）超过 5%，且会直接影响结论。
- 某个版式整组过不了校验，需要决定「继续攻」还是「先隔离交付」。
- 要覆盖/删除旧产出、要改业务真源表、要接入线上系统——这些都不是抽取动作。

## 边界

- 不做扫描件 OCR 全流程（本技能针对有文字层的 PDF；扫描件先过 OCR 再进来）。
- 不直接写业务真源表、不改云函数、不做品牌分包——抽取产出是**上游**，接入另走。
- 不猜。样本没印的就是没有，宁可空着并记进页清单，也不要从相邻行「补」一个值
  （泰珂洛 p68 的 `RE=1.6` 就是从上一行串过来的，看着完全合理）。
