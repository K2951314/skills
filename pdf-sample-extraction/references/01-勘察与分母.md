# 01 勘察与分母

> 这一篇决定后面所有工作的正确性。分母错了，后面抽得再干净也是错的。

## 为什么必须先定分母

真实案例对比：

| 案例 | 做法 | 结果 |
|---|---|---|
| 泰珂洛切削参数（旧） | 按「页面上有 vc 字样」捞页，直接抽 | 640 行，ap/f 空 **97.7%**——只有第 1 页（p354）表头识别成功 |
| 京瓷切削参数（旧） | 按行取文本 | 1394 行，四列齐全 **3 行（0.2%）**，`Vc` 列装的是正文段落 |
| 泰珂洛切削参数（新） | 先做页清单（70 页 / 74 页命中），逐页记表头签名 | 835 行，ap 100%、f 91.7% |
| 京瓷全矩阵（新） | 先按列名组合分类出 237 页候选 | 184 行，零差异 |

**结论**：不是抽取算法的问题，是**候选页集合**的问题。旧产出「看起来有 1394 行」，
掩盖了「抽的根本不是表」这个事实。

## 三条互相独立的证据线

刻意绕开抽取脚本和既有验收报告，否则只是自证：

| 线 | 做法 | 得到什么 |
|---|---|---|
| **A 应有** | `doc.get_toc()` 读书签 + 全页按字号扫标题（`span.size >= 12`） | 「样本里到底有哪些章节」→ 分母 |
| **B 实有** | 扫盘统计产出的行数/列数/空值率/残缺值/重复主键/页码区间 | 分子 |
| **C 对不对** | 对 A/B 差异最大的位置，逐页 dump 原文坐标肉眼比对 | 真伪判定 |

只有 A 和 B 对得上、且 C 抽点全过，才能说「这一类抽完了」。

### A 线的两个坑

1. **书签页码 ≠ PDF 物理页**。`get_toc()` 给的是 PDF 页序（1-based），但印刷页码通常差几十页。
   样本目录页写的「技术资料 P.1009～」对应物理 p1010–1018，差 1 页是常态，差几十页也见过。
2. **整册漏扫**。泰珂洛勘察阶段只扫了车/铣/钻三册，**漏了《UsersGuide》整册 180 页**，
   而故障对策全在那一册的 L 章（p29–160，132 页）。教训：勘察第一步是 `ls` 全部册，
   把「每册 → 页数 → 章节数」列出来，再逐册扫。

### B 线的规则化体检（R1–R6）

对每张产出表跑同一套规则，一次看清哪张表有病：

| 规则 | 判据 | 典型信号 |
|---|---|---|
| R1 残缺区间 | 值匹配 `^\d+\.?\d*\s*[-–]$` 或 `^[-–]$` | `vc='50-'`、`f='0.01-'` → 区间右端被吃掉 |
| R2 数值越界 | 数值列出现非数值 / 超出物理区间 | `RE='-'`、`vc=-9`（原文 `0.3-9` 左端被吃） |
| R3 型号截断 | 型号含 `...` 或 `**` | `CTFVR/L2525-3T...` |
| R4 型号含空格/逗号 | `MS7025, VP15TF` | 多个牌号挤进型号列 |
| R5 重复主键 | 同主键多行 | 要先判「合法多行（并集）」还是「重复抽取」 |
| R6 整列全空 | 非空率 0 | 通常是版式里根本没这列，硬留了个字段 |

⚠ **R5 要小心**：同一个 `(品牌, 型号)` 允许多行（分页、分刃口、跨页牌号不同），语义是**并集**。
任何清洗脚本按 key 去重重建整表都会静默吃数据（真实踩过：丢 262 行 / 120 个牌号）。

## 页清单：分母的载体

字段设计（照抄，够用）：

| 字段 | 说明 |
|---|---|
| `page` | PDF 物理页（1-based） |
| `chapter` | 章号，从书签的章起始页推 |
| `layout` | 版式分类，**按列名组合判**（见下） |
| `n_range` | 页内 `\d+\s*[~～\-]\s*\d+` 的命中数——真参数表一定成片 |
| `n_has_speed` / `n_has_feed` / `n_has_depth` | 关键词计数，用来判「是不是这类参数表」 |
| `n_triplet` | `下限－推荐－上限` 这类三元组表头出现次数 |
| `n_rows_extracted` | 抽出行数（抽完回填） |
| `reject_reason` | 拒绝原因（抽完回填） |

### 分类必须按「列名组合」，不能按关键词

```
full_matrix  加工形态 + 推荐断屑槽 + Vc     → 车削全矩阵（三元组）
milling      加工材料 + fz + Vc             → 铣削
drilling     加工材料 + 加工径 + Vc         → 钻孔
other        有「推荐切削参数」标题但三套列名都不齐 → 人工看
noise        只有标题、n_range < 6          → 目录/说明/材质 lineup
```

按「有没有 vc 字样」分类会把正文段落页全捞进来——京瓷旧产出就是这么坏的。

### 噪声页判据

- 只有标题、没有成片数值区间（`n_range < 6`）→ 目录页、样本用法说明页、材质 lineup 页。
- 有框线但只有两三行 → 图例、小规格表，不是参数表。
- 整页只有一个大字号词 → 章节封面。

京瓷实测：候选 431 页 → 可解析 237 页，噪声 194 页（45%）。**这 45% 就是旧产出的来源。**

## 分母怎么定义（最容易写错的一句话）

> 「ap 非空率」的分母不是全表行数，是**该表块确实有 ap 列的行**。

泰珂洛车削册 835 行里，大量表（切槽/切断/螺纹）原文只有 vc + f，根本没有切深列。

| 分母口径 | ap 非空率 | 含义 |
|---|---|---|
| 全部 835 行 | 24% | 看着像残缺 |
| 有 ap 列的 204 行 | **100%** | 实际完整 |

验收报告里必须写清用的是哪个分母，否则「24%」会被当成抽取失败。
